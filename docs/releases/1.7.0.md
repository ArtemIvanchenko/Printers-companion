# Printer's Companion 1.7.0

Обновление архитектуры, надёжности импорта и проверок достоверности аналитики.
Версия аналитики: **0.5.1**. Вычисления остаются на ПК операторов;
NAS используется только для PostgreSQL и MinIO.

## Что вошло

- Единая интерпретация сессии и компактный снимок аналитики для отчёта,
  карточки и оценки риска. Проверки не позволяют смешивать разные поколения
  результатов. Чтение отчётов отделено от разбора исходников.
- Импорт и восстановление браузерных загрузок выделены в сервисы;
  усилены контроль происхождения файлов, проверка актуальности результатов
  и публикация после завершения расчёта.
- Анализ доступного полного потока телеметрии отделён от прореженного графика;
  ограничения и неполнота источников сохраняются явно.
- Сравнение плана и факта едино для карточки и каталога. Неполные тайминги
  не выдаются за измеренное время всей печати, а неизвестное время — за ноль.
- Калибровка прожига проверяет машину и полный состав настроенных параметров.
  Несовместимая модель не переносится на другой режим. Модель цикла отдельно
  проверяет определимость межфазной добавки и минимального времени слоя.
- Усилены проверки ML: историческая разметка не считается будущей проверкой,
  ошибки повторных печатей не погашаются усреднением. Экспериментальный анализ
  запускается отдельным ограниченным по времени owner-local заданием.
- Большой код интерфейса разделён на тематические файлы. Графики, 3D-библиотеки
  и шрифты поставляются локально с лицензиями и контрольными суммами.
- Закрыта HTML-инъекция в чате: вопрос, ответ модели и сообщения об ошибках
  экранируются; HTTP-ошибка не выдаётся за успешный ответ.
- Проверка готовности отделена от проверки работающего HTTP-процесса.
  Обновляторы проверяют готовность зависимостей и SHA запущенного API;
  для NAS добавлена диагностика без SSH.
- Зависимости контейнеров генерируются из pyproject.toml; сборки сохраняют
  версию и SHA. Проверка CI включает реальный PostgreSQL и запуск собранного API.
  Публикация контейнеров по тегу разрешена только после успешного CI этого SHA.

## Важные ограничения

- Этот релиз **не подтверждает точность прогноза времени на реальных печатях**.
  Для независимой оценки нужны подтверждённая связь модель–лог, полная
  геометрия с поддержками, реальный рецепт станка и нормальное машинное время.
- Нативные поддержки Magics без экспортированных STL не декодируются полностью;
  такой геометрический прогноз остаётся ограниченным/нижней оценкой.
- Настроенные в карточке числа сами по себе не доказывают реально выполненный
  режим печати. Согласование OLD/NEW подтверждает счётчик, но не отсутствие
  остановки внутри фазы. Неполные логи полезны для диагностики отдельных слоёв,
  а не для процента ошибки всей печати.
- Независимая held-out проверка модели полного нормального цикла ещё не
  реализована. Теневая аналитика — эксперимент, не подтверждение брака.
- Старые результаты аналитики не переписываются автоматически. Для нового
  поколения требуется повторный анализ исходников; применимость старых
  калибровок может быть отклонена защитами.
- Удалённая установка на NAS/другом Mac не проверялась в рамках этого релиза.
  CI контейнеров не заменяет проверку конкретного операторского окружения.

## Обновление

При обновлении сохраняйте рабочие .env, тома БД, MinIO, локальную очередь и
идентификатор ПК. Не используйте команды удаления томов и не меняйте пароль
существующей БД установочным шаблоном. GitHub предоставляет архив исходников
релиза; контейнеры публикуются в GHCR с тегами api-v1.7.0, worker-v1.7.0,
scheduler-v1.7.0, watcher-v1.7.0, mcp-v1.7.0 и base-v1.7.0 (linux/amd64).
На Apple Silicon для нативных ARM-контейнеров используйте сборку из исходников.
