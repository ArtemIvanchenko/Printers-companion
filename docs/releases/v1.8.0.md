# Printer’s Companion 1.8.0

## Для операторов

- Первые отдельные установщики macOS (Apple Silicon и Intel) и Windows x64.
  Python, Git и Node.js для установленного клиента не нужны.
- Сохранены карточки, STL/Magics, вложения, импорт логов, аналитика и расчёт
  времени. Вычисления остаются на ПК, PostgreSQL/MinIO — на NAS.
- Настройки, идентификатор ПК и очередь незавершённых загрузок находятся вне
  приложения. При замене пакета они не удаляются.
- Обновление вычислительной части проверяет точные SHA/digests, ожидает свободную
  очередь и завершение принятых загрузок, сохраняет прежние образы для отката.
- Упрощены импорт, чтение отчётов и послойные вычисления. Оптимизированы нарезка
  и отбор линий штриховки без замены геометрии поддержек заполненным телом.

## Важные ограничения этого выпуска

Установщики **тестовые и неподписанные**. Публичный автоматический канал отключён:
обновление настольного пакета пока выполняется вручную новым установщиком.
Не отключайте защиту ОС глобально. Подпись/нотаризация и проверка обновления A→B
нужны до обещания автоматического обновления «одной кнопкой» на всех ПК.

Старая контейнерная установка 1.7.0 не поддерживает новый протокол завершения
записей. Её принудительная остановка установщиком запрещена. Сначала требуется
согласованный переход с резервной копией, завершением работ и проверкой путей.
Новая установка подключается к уже подготовленной общей БД; автоматической
миграции или переустановки NAS нет.

Точность времени всей реальной печати ещё не подтверждена. Неполные логи,
неподтверждённые поддержки/режимы и неизвестный полный нормальный цикл остаются
ограничениями; исследовательские RS320/LaserStudio сценарии не включены в
рабочий оценщик. Прохождение тестов не доказывает точность прогноза.

Инструкция: [работа и обновление](../OPERATOR_GUIDE.md).
`operator-images.json` связывает установщики с контейнерами этого релиза;
`SHA256SUMS.txt` содержит контрольные суммы опубликованных файлов.
