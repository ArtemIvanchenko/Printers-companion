# Папка печати и импорт каталога

## Каталог на рабочем столе

`/Users/admin/Desktop/Каталог моделей и печатей` собран без перемещения оригиналов.
Все копии моделей проверяются SHA-256; ZIP совместим с Finder/Проводником.
Каждый архив проверяется распаковкой в поток и SHA каждого логового файла.

```text
Каталог моделей и печатей/
  01 Печати с моделями и логами/
    <печать>/
      print-bundle.json
      Логи.zip
      Модели/
        <имя модели>__<SHA>/
          <исходный STL или Magics>
          Логи всей печати.zip
          print-bundle.json
  02 Модели без установленных логов/
    <имя модели>__<SHA>/
      <исходная модель>
      print-bundle.json
  03 Логи без установленной модели/
    <набор>/Логи.zip
  04 Ранние версии логов/
    Не импортировать повторно.zip
```

Снимок сборки: 614 уникальных моделей, 148 уникальных логов. Раздел 01 содержит
8 архивных печатей (86 уникальных моделей, повторы между печатями сохраняются);
раздел 02 — 528 моделей без связи; раздел 03 — 19 наборов логов без модели.
Около 2,7 ГБ логического объёма. Дубликаты ZIP возле деталей независимы от оригинала;
на APFS применяется copy-on-write, если доступен. Это НЕ отдельные измерения детали.

Сборщик: `python -m scripts.maintenance.organize_print_catalog`. Использует проверенные
`inventory.json` и `import-plan.json` из `.operator-state/desktop-import`, не добавляет
карточки в БД. Повторный запуск сверяет существующие модели и архивы, а не заменяет
отличающееся содержимое. Обычный Desktop inventory исключает созданный каталог.

## Контракт версии 1

`print-bundle.json` содержит `schema_version: 1`, `kind`, `bundle_id`, `name`,
`association`, `warning_ru`, а также `files`: относительный `path`, `role`,
`sha256`, `size`. Для каталогов вместо файлов хранится индекс `bundles`.

- `print`: одна плита/печать, модели и один комплект логов.
- `model`: модель без установленной связи с логами.
- `logs`: набор логов без модели; импортируется без выдуманной карточки модели.
- `model_reference`: отдельный компонент общей печати. Импортировать нужно
  родительскую папку печати, иначе потеряется состав плиты.
- `catalog`: индекс всего каталога, не одна печать. Массовое создание карточек из
  корня намеренно запрещено.

`record_id_hint`, имена, даты и пояснения — справочные данные, а не разрешение
перепривязать карточку. Пользователь сам выбирает существующую карточку. Архивная
связь не означает проверенную годность, известный пресет или подтверждённый Z.

## Интерфейс импорта

1. «Добавить печать» → выбрать или перетащить одну папку.
2. Предварительный разбор показывает только состав выбранного пакета. Повторные
   ZIP возле отдельных деталей не загружаются второй раз.
3. Оператор проверяет состав и отмечает подтверждение. Без манифеста дата и
   соседство файлов не считаются доказательством связи; несколько Magics отклоняются.
4. Создать карточку или явно выбрать существующую. При частичной ошибке созданная
   карточка остаётся выбранной для повторной попытки, не создаётся новая автоматически.
5. Загрузки сверяются с ожидаемыми SHA из манифеста по ответу сервера. Ошибки и
   пропуски показываются, не подменяются сообщением об успешном завершении.
6. Парсинг логов начинается через обычное подтверждение задания импорта.

Отправка нескольких вложений и логов не является одной общей транзакцией: успешно
принятые файлы сохраняются при ошибке следующего файла. Повторное добавление модели
в ту же карточку дедуплицируется по SHA. Отдельный повторный запуск всей формы с
выбором «Новая» всё ещё может создать отдельную карточку — это выбор оператора.

## ZIP и worker

`domain/services/log_archives.py` раскрывает ZIP, загруженные и непосредственно,
и внутри папки. Сначала архив сохраняется в MinIO; только потом раскрывается локально.
Парсеру передаются только `.log`; модель/README/сам ZIP не становятся псевдосессиями.
Ссылка на исходный ZIP и `archive_member_path` сохраняются в происхождении файла.

Одинаковое имя и содержимое логов разбирается один раз. Разное содержимое с одинаковым
именем останавливает пакет: оператор должен разделить источники. Блокируются выход
за корень, символические ссылки, повторные имена, ZIP внутри ZIP. Ограничения: до
10 000 членов, 6 ГиБ на файл, 20 ГиБ распакованного пакета, проверка свободного места.
Для вложенных архивов глубже одного уровня требуется предварительная ручная распаковка.

## Показ карточек и расчёт времени

Сетка запрашивает 10 карточек, «Ещё» добавляет следующие 10. Фильтр сбрасывает
позицию; устаревший сетевой ответ не заменяет новый фильтр. Дополнительные фильтры
не ограничены первыми 100 записями. Сортировка имеет стабильный второй ключ record_id.

Для расчёта нужны API и `worker.estimate_tasks`, для импорта — `worker.tasks`.
`desktop_runtime.py start` запускает оба локальных worker с блокировкой повторного
старта. Прогресс расчёта находится в видимом блоке `estimate-status`; карточка
восстанавливает опрос своего активного задания после перезагрузки.
Задание для изменившейся версии карточки отклоняется до тяжёлого расчёта.
Наличие работающего worker не означает готовую оценку: источником готовности
является `BackgroundJob.status=done` и сохранённый снимок в карточке.
