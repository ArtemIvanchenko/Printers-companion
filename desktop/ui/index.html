Ваши печати.
Всё в одном месте.

Первое подключение

Укажите реквизиты уже настроенного NAS. Программа не переустанавливает базу данных.

В этом тестовом пакете ещё нет новой вычислительной сборки. Он проверяет окно и подключение существующей установки; создавать новую пока нельзя. Реквизиты NAS вводить не нужно.
